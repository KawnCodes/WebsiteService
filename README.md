# WebsiteService

A website-as-a-subscription business for independent hospitality venues in Cambridge, UK. We build, host and maintain each venue's site for a monthly fee, and an AI agent handles most of the delivery.

- `PROGRESS.md`: checklist and decisions log (start here)
- `docs/`: strategy and plans, one file per phase
- `site/`: the agency's marketing website and demo sites
- `ops/`: templates, trackers and scripts
