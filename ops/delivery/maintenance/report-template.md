# Monthly client report

Send by WhatsApp or email in the first week of the month. The agent drafts it and the founder sends it. Keep it short, because owners read these between services.

## Core (one-liner)

> Hi {first name}, {month} at {venue}'s website: all healthy ✅ (online {uptime}% of the time). We made {n} changes for you ({short list}). Coming up: {seasonal nudge, e.g. "want me to add your Christmas hours?"}. {founder first name}

## Plus and Group

**Subject:** {venue} website: {month} report

Hi {first name},

**At a glance**
- 🟢 Site online {uptime}% of the month. Mobile speed score {score}/100.
- 👀 **{visits} visits** ({change vs last month}). Top pages: {page 1}, {page 2}.
- 📩 **{enquiries} private-hire/event enquiries** through the site form.
- 🔗 {booking clicks} clicks on "Book a table". *(Only if tracked: Cloudflare Web Analytics counts page views, not clicks. Leave this out unless we've set up tracking.)*
- 📍 Google Business Profile: {views or actions, if available}. Posted: "{post title}".

**What we did**
- {change 1} ({date})
- {change 2} ({date})
- Monthly checks: links, hours, speed and security updates ✅

**Your allowance:** {n} of {allowance} changes used.

**Next month**
- {seasonal suggestion or small improvement we'll make}
- {anything we need from them}

Any questions, just reply.
{founder first name}

---

### Where the numbers come from
| Number | Source |
|---|---|
| Uptime | UptimeRobot dashboard |
| Visits, top pages | Cloudflare Web Analytics for the client's site |
| Enquiries | Count of Web3Forms submissions (in its dashboard, or the client's inbox) |
| Speed score | PageSpeed Insights, mobile |
| Google Business Profile | The profile's "Performance" view (Plus and Group only, as a Manager) |

**Report honestly.** Never invent or round up numbers. If visits went down, say so and suggest a reason or a fix. Don't attribute bookings to the website unless they're tracked.
